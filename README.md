# Points Calculator - Hibachi

An intuitive and efficient web application designed to calculate and track points for the Hibachi platform. This tool helps users easily monitor their activities, estimate rewards, and optimize their participation.

🌐 **Live Website:** [https://points-calculator-hibachi.vercel.app/](https://points-calculator-hibachi.vercel.app/)

---

## 🚀 Key Features

* **Instant Calculations:** Automatically computes your total points based on your current inputs and tasks.
* **Always Online:** Fully deployed and accessible from any device (Desktop or Mobile).
* **Clean & Fast UI:** Designed to be lightweight, simple, and direct.
* **Just for Fun:** Built as an independent side project to help the community.
